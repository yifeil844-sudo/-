# 步频模拟器

让 iPhone 的支付宝运动显示每分钟 140-190 步，可随时开关。

---

## 快速开始

### 第一步：安装 Python（只需一次）

1. 打开 [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. 点击黄色 "Download Python 3.x.x" 按钮下载
3. 运行安装包，**务必勾选 "Add Python to PATH"**，然后点 Install Now

### 第二步：运行程序

双击 `start.bat` 文件即可启动界面。

---

## 两种使用方案

### ✅ 方案一：iPhone 快捷指令（推荐）

**优点**：一次设置，以后只需在手机上点一下开关，不需要电脑。

打开程序后切换到「📱 快捷指令（推荐）」标签页，按照里面的图文教程在 iPhone 上操作一遍。

**开关方式**：
- 🟢 开启：打开「快捷指令」App → 点「步频器」→ 点 ▶️
- 🔴 关闭：从底部上滑 → 找到快捷指令进程 → 上滑关闭

### 📂 方案二：生成文件导入（备用）

**适合**：iOS 16 以下，或快捷指令设置困难时使用。

1. 在程序「生成步数文件」标签页中配置时间和步频
2. 点「生成步数文件」→ 点「开启传输服务器」
3. iPhone 和电脑连同一个 WiFi，用相机扫描二维码
4. App Store 安装「**Health Import**」（免费，搜索 Health Import）
5. 用 Health Import 打开下载的 CSV 文件，点导入

## 常见问题

**Q：支付宝没有显示步数？**  
A：支付宝每隔几分钟同步一次苹果健康。进支付宝 → 运动 → 下拉刷新，等 1-3 分钟。

**Q：快捷指令里找不到「记录健康样本」？**  
A：该功能需要 iOS 16.0 或更高版本。  
检查方法：设置 → 通用 → 关于本机 → 软件版本。

**Q：快捷指令运行一会儿就停了？**  
A：手机锁屏后后台会受限。建议插上充电线使用，并在「设置 → 显示与亮度 → 自动锁定」改为「永不」（用完记得改回来）。

**Q：需要授权怎么办？**  
A：首次运行快捷指令时，系统会弹出「允许访问健康数据」的提示，点「允许」即可。

**Q：扫码后 Safari 显示一堆数字？**  
A：长按页面 → 选「下载链接」→ 再用 Health Import 打开下载的文件。
