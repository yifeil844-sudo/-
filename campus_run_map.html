🏃 校园跑 GPS 路线生成器

1 在卫星地图上画操场路线

找到你的操场 → 沿跑道边缘依次点 4~8 个点
自动连成闭合环形路线

    2 设置跑步参数

    3 用 3uTools 注入 iPhone GPS

    ① 下载安装 3uTools
      浏览器打开 www.3u.com → 下载安装

    ② 连接 iPhone
      USB 数据线连电脑 → 手机点「信任」

    ③ 打开虚拟定位
      3uTools 顶部 → Toolbox → VirtualLocation

    ④ 导入 GPX 文件
      点 「…」或 Load GPX → 选刚才下载的 GPX 文件

    ⑤ 开始模拟
      点 Start Simulation / Walk
      速度用默认就行（已写入 GPX）

    ⑥ 打开支付宝校园跑打卡
      同时配合摇步器产生步频

    GPS 由 3uTools 注入 ｜ 步频需配合摇步器
